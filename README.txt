PRETTYUS RECOVERED FO F PAGES — GITHUB PAGES EDITION

This package contains the homepage and the full content of the eight public FoF Pages in your FreeFlarum backup, recovered October 2026.

PUBLICATION: IMPORTANT
1. Extract this ZIP on your computer / phone first.
2. In GitHub create/open a repository for this website (for example PrettyUs-pages).
3. Upload ALL the contents of the extracted folder to the repository root. The file index.html MUST be at the repository root (not inside a nested folder or left inside the ZIP).
4. In repository Settings > Pages, select "Deploy from a branch", branch "main", folder "/ (root)", then Save.
5. GitHub will provide a site URL such as https://YOURNAME.github.io/PrettyUs-pages/.
